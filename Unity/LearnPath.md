### 🔵 ФАЗА 3 — КОНТРОЛИРУЕМАЯ ПРАКТИКА

**Длительность: 5 недель (16.09 — 21.10.2026)**

**Цель:** автоматизм на связке всех MVS-инструментов в одном мини-проекте

**Конкретные действия:**

- Взять свою игровую идею и реализовать в ней одну полную фичу с нуля: Domain → Application → Infrastructure → Presenter + VContainer + UniTask + R3/MessagePipe
- Одна сессия = один аспект (не пытаться "всё сразу")
- Каждую сессию: 5 мин retrieval (что делал прошлый раз без подглядывания) → 30-90 мин практика → 10 мин рефлексия + дневник

**Структура сессии:**



```csharp
[5 мин]   Retrieval: объяснить себе вслух или письменно

[70 мин]  Целевая практика одного аспекта (например: 
          только слой Application для одной фичи)
[15 мин]  Рефлексия: что вышло / что нарушил / 
          где срезал углы в архитектуре
[5 мин]   Запись в дневник + план следующей сессии
```

**Phase Demo:**



```csharp

через неделю без автора. Объясняю вслух 
почему Presenter не вызывает Infrastructure
```
