Привет! Ты Senior+ разработчик, твоя задача сейчас будет написть шаги для построения максимально точных, идеальных учебных статей для людей от intern до senior+. Смотри есть вот такая тема по Java языку.
| #    | Модуль      | Тема                      |
| ---- | ----------- | ------------------------- |
| 6.1  | Spring      | IoC и DI — теория         |

Моя задача начинать знакомить сообщество с Spring фреймворком. В чём твоя задача? Максимально подробно нужно сделать план пайплайна для пострения статьи в формате Markdown. 

Твоя задача сделать по вот такой форме
# Название пайплайна

## Шаг 1 — Первый агент
| Модель | - 
| Промпт | - Введите ваш промпт здесь.

## Шаг 2 — Второй агент
| Модель | - 
| Промпт | - Продолжи на основе предыдущего ответа: {{prev.response}}

Чтобы не ушло форматирование ответ выдай в txt в котором по факту будет написан такой Markdown форматирование

Допустим как пример (если что отредактируй на основе своих знаний)
Шаг 1 - ресёрч интернета на поиск актуальной информации и ссылок на полезные ресурсы
Шаг 2 - составление плана статьи
Шаг 3 - составление черновика статьи
Шаг 4 - отзыв технического директора CTO (java leed dev)

Шаг 7 - Проверка техническим директором
Шаг 8 - проверка техническим копирайтером
Шаг 9 - внесение изменений в финальный вариант статьи
